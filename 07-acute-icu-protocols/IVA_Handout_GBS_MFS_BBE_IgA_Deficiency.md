### Tolkning

CRP-trenden (186→31) visar att pip/tazo har effekt mot bakteriemin. Men:

1. **Temp normaliserades (37,1) och steg igen (38,0)** — detta mönster kräver förklaring
2. **CRP-studs 31→55** speglar troligen febern 10/4 (24h fördröjning) — men kan även signalera:
   - Kvarvarande bakteriellt fokus som inte sanerats
   - **Candida-genombrott** (se nedan)
   - Dysautonomi (pendlar aktivt — BT svänger mellan 94/46 och 154/64)
3. **Utan PCT kan vi inte skilja bakteriell feber från dysautonom feber eller candida**

## Candida — riskbedömning

Madeleine har **nio samtidiga riskfaktorer** för invasiv candida:

| Riskfaktor | Status | Evidens |
|------------|--------|---------|
| IVA >14 dagar | **Ja (22 dagar)** | |
| Respirator >10 dagar | **Ja (22 dagar)** | |
| CVK in situ | **Ja** (troligen) | |
| Bredspektrum AB >7 dagar | **Ja (~10 dagar pip/tazo)** | OR 5,6 (Thomas-Ruddel 2022) |
| Kortikosteroider | **Ja** (Solu-Medrol avslutad 2/4) | Trycker Th17, kvarstår ~2 veckor |
| **Selektiv IgA-brist** | **Ja (medfödd)** | 18,5% svampinfektion (Vosughimotlagh 2023) |
| Tidigare candidainfektion | **Ja (ungdomen)** | |
| Leverförsämring | **Ja (ASAT ↑)** | |
| Dysautonomi (GI-translokation) | **Ja** | |

**PCT-ledtråd:** PCT 0,12 (1/4) är **lågt**. Vid candidemi är PCT typiskt lågt (median 0,29 vs 1,73 vid bakteriell; Kokkoris 2024). **Lågt PCT + stigande CRP + riskfaktorer = överväg candida, inte bara autonom feber.**

**BDG (beta-D-glucan):**
- ≥80 pg/mL: misstänkt invasiv candida (Kazancioglu 2022)
- ≥112 pg/mL: trolig — starta echinocandin
- **Högt negativt prediktivt värde** — negativt BDG utesluter i stort sett invasiv candida
- **Har aldrig beställts trots hög riskprofil**

**Svampodling:** Beställd 4/4 — svar aldrig rapporterat.

## Autonom feber vs infektion — beslutsalgoritm

29% av GBS-patienter med dysautonomi har autonom feber (Chakraborty 2020). Madeleines dysautonomi pendlar aktivt (BT 94/46 → 154/64 på 12 timmar) — temperaturpendling kan vara del av samma mönster.

| PCT-resultat | CRP-trend | Trolig orsak | Åtgärd |
|---|---|---|---|
| **<0,25** | Fallande/stabil | **Autonom feber** | Optimera sedering. Överväg dexmedetomidin. |
| **<0,5** | Stabil/stigande | **Svamp möjlig** | BDG, svampodlingar, överväg echinocandin |
| **>0,5** | Stigande | **Bakteriell** | Omvärdera AB utifrån resistensbesked |

**Utan PCT-värde kan denna differentiering inte göras.**

## Extra alert — specifikt för denna patient

### Post-steroid infektionsfönster

Solu-Medrol avslutades 2/4. Immunsuppression kvarstår uppskattningsvis till ~16/4. Förhöjd bevakning:
- Temperatur: kontinuerlig (ny probe). CRP dagligen. **PCT: bör tas nu.**
- Blododlingar vid varje ny feberepisod (gjort 10/4 — bra).
- Låg tröskel för empirisk eskalering hos IgA-deficient patient.

### Leverövervakning

Försämrade levervärden (uppmärksammat ~2/4, specifika värden okända). Möjliga orsaker:

| Orsak | Mönster | Åtgärd |
|---|---|---|
| **Pip/tazo-DILI** | ALP/GT-stegring (kolestatiskt) | LFT 2×/vecka, överväg byte |
| **Paracetamol** | ALAT-stegring | Max 2 g/dag vid leverpåverkan; sätt ut vid ALAT >5× ULN |
| **Hepatosplenic candida** | ALP/GT + kvarstående feber | Ultraljud buk, BDG |
| **Ischemisk hepatit** | Massiv ALAT-spike efter hypotension | Korrelera med hemodynamik |

### Levotyroxin — aldrig avbryta

Madeleine har Hashimotos. Levotyroxin MÅSTE ges dagligen — avbrott >3–5 dagar = risk för myxedemkoma (mortalitet 25–60%). Symptomen maskeras helt av GBS.

- **Via sond:** Flytande form. Håll sondmat 1 timme före OCH efter.
- **Monitorering:** TSH + FT4 veckovis. Mål TSH 0,5–2,5.
- **Heparin:** Falskt förhöjt FT4 — mät >1h efter IV heparin, >10h efter LMWH.
- **Kortison:** Trycker TSH — lita inte enbart på TSH post-IVMP, följ FT4.

### Hypofosfatemi och respiratoravvänjning

Fosfat-infusion insatt 11/4 — tyder på hypofosfatemi. Vid GBS:
- Fosfatbrist ger muskelsvaghet och försvårar weaning (kritiskt vid redan total paralys)
- Bör korrigeras till normalvärde innan spontanandningsförsök (SBT)
- Kontrollera fosfat dagligen under ersättning

## Undvik — specifikt för denna patient

| Undvik | Varför |
|--------|--------|
| **FFP vid transfusion** | Innehåller IgA (~200 mg/dL). Använd albumin (säkert, negligerbar IgA). Tvättade erytrocyter om transfusion behövs och anti-IgA-status okänd. |
| **Rent selektiva betablockerare vid dysautonomi** | Risk för asystoli — kan avmaskera bradykardi. Labetalol (α+β) används nu med försiktighet. Dexmedetomidin är alternativ. |
| **Långverkande antihypertensiva** (amlodipin, ACE-hämmare) | Rebound-hypotension vid GBS-dysautonomi. Använd enbart kortverkande medel. |
| **Dexmedetomidin-bolus** | Bradykardi-risk hos dysautonoma patienter. Ge enbart som infusion 0,2–1,4 µg/kg/h. |
| **Tricykliska antidepressiva** | Förvärrar autonom instabilitet, urinretention, ileus. |
| **Paracetamol >2 g/dag** | Levervärden redan försämrade. |
| **Abrupt sederingsstopp** | Utlöser autonom storm. Trappa ned gradvis. |
| **Aggressiv BT-behandling** | Dysautonomi = snabba svängningar. Tolerera bredare BT-range (90–180 systoliskt). Iatrogen overshoot är största risken. |
| **IVIg utan anti-IgA-svar** | Anti-IgA beställd 31/3, svar inväntas. Vid IgA-brist + anti-IgA-antikroppar: risk för anafylaxi. |

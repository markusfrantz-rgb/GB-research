## Extra alert — specifikt för denna patient

### 1. Candidarisk (hög)

Madeleine har **fyra samtidiga riskfaktorer** för invasiv candida:

- Bredspektrum antibiotika (OR 5.6 för invasiv candida; Thomas-Ruddel 2022, meta-analys)
- Kortikosteroider (Solu-Medrol — trycker ner Th17, kritiskt för antifungalt försvar)
- IgA-brist (sekretoriskt IgA hindrar candida-invasion; 18,5% svampinfektion vid IgA-brist; Vosughimotlagh 2023)
- Tidigare candidainfektion

**Övervakning:**
- Beta-D-glucan (BDG): ≥80 pg/mL misstänkt, ≥112 pg/mL trolig (Kazancioglu 2022). Högt negativt prediktivt värde — negativt BDG utesluter i stort sett invasiv candida.
- Svampodlingar (trakeal, urin, rektum) — kolonisationsindex >0,5 predikterar invasion
- Candida Score: TPN (1p) + kirurgi (1p) + multifokal kolonisation (1p) + svår sepsis (2p). ≥3 = överväg antifungal.

**OBS — PCT vid candidemia:** PCT är typiskt **lågt** vid svampinfektion (median 0,29 vs 1,73 vid bakteriell; Kokkoris 2024). Lågt PCT + feber + riskfaktorer = överväg candida, inte bara autonom feber.

### 2. Autonom feber vs infektion

29% av GBS-patienter med dysautonomi har autonom feber (Chakraborty 2020). Madeleines CRP faller (pip/tazo fungerar) men hon har fortfarande 39°C. Möjliga tolkningar:

| PCT-resultat | CRP-trend | Trolig orsak |
|---|---|---|
| **<0,25** | Fallande | **Autonom feber** — optimera klonidin/dexmedetomidin |
| **<0,5** | Stabil/stigande | **Svamp möjlig** — BDG, svampodlingar |
| **>0,5** | Stigande | **Bakteriell** — omvärdera AB |

### 3. Post-steroid infektionsfönster

Solu-Medrol avslutades 2/4. Immunsuppression kvarstår ~2 veckor. Förhöjd bevakning:
- Temperatur kontinuerlig. CRP + PCT dagligen under detta fönster.
- Blododlingar vid varje ny feberepisod.
- Låg tröskel för röntgen vid ändrade luftvägssekret.

### 4. Leverövervakning

Försämrade levervärden (uppmärksammat ~2/4). Möjliga orsaker:

| Orsak | Mönster | Åtgärd |
|---|---|---|
| **Pip/tazo-DILI** | ALP/GT-stegring (kolestatiskt) | LFT 2×/vecka, överväg byte |
| **Paracetamol** | ALAT-stegring | Max 2 g/dag vid leverpåverkan; sätt ut vid ALAT >5× ULN |
| **Hepatosplenic candida** | ALP/GT + kvarstående feber | Ultraljud buk, BDG |
| **Ischemisk hepatit** | Massiv ALAT-spike efter hypotension | Korrelera med hemodynamik |

### 5. Levotyroxin — aldrig avbryta

Madeleine har Hashimotos. Levotyroxin MÅSTE ges dagligen — avbrott >3–5 dagar = risk för myxedemkoma (mortalitet 25–60%). Symptomen maskeras helt av GBS.

- **Via sond:** Flytande form. Håll sondmat 1 timme före OCH efter.
- **Monitorering:** TSH + FT4 veckovis. Mål TSH 0,5–2,5.
- **Heparin:** Falskt förhöjt FT4 — mät >1h efter IV heparin, >10h efter LMWH.
- **Kortison:** Trycker TSH — lita inte enbart på TSH post-IVMP, följ FT4.

## Undvik — specifikt för denna patient

| Undvik | Varför |
|--------|--------|
| **FFP vid transfusion** | Innehåller IgA (~200 mg/dL). Använd albumin (säkert, negligerbar IgA). Tvättade erytrocyter om transfusion behövs och anti-IgA-status okänd. |
| **Betablockerare vid dysautonomi** | Risk för asystoli — kan avmaskera bradykardi. Dexmedetomidin föredras. |
| **Långverkande antihypertensiva** (amlodipin, ACE-hämmare) | Rebound-hypotension vid GBS-dysautonomi. Använd enbart kortverkande (esmolol, klonidin). |
| **Dexmedetomidin-bolus** | Bradykardi-risk hos dysautonoma patienter. Ge enbart som infusion 0,2–1,4 µg/kg/h. |
| **Tricykliska antidepressiva** | Förvärrar autonom instabilitet, urinretention, ileus. |
| **Paracetamol >4 g/dag** | Levervärden redan försämrade. Max 2 g/dag vid leverpåverkan. |
| **Abrupt sederingsstopp** | Utlöser autonom storm. Trappa ned gradvis. |
| **Aggressiv BT-behandling** | Dysautonomi = snabba svängningar. Tolerera bredare BT-range (90–180 systoliskt). Iatrogen overshoot är största risken. |

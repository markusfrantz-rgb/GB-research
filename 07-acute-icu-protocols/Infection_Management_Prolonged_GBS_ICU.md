# Infection Management in Prolonged GBS ICU Stay

Nosocomial infections complicate up to 87% of GBS ICU admissions. Bacteremia occurs in 11.6% and candidemia in 4.7% of mechanically ventilated GBS patients (Alqahtani et al., 2024). This document provides evidence-based protocols for empirical antibiotic selection, escalation, catheter-related bloodstream infection (CRBSI) management, PCT-guided stewardship, and antibiotic safety in patients with IgA deficiency and hepatic impairment.

## 1. Common Organisms in Prolonged GBS ICU Stay

ESKAPE pathogens dominate after >14 days in ICU. *[Level 2 — large epidemiological cohort]*

| Organism | Clinical Context | Resistance Concern |
|----------|-----------------|-------------------|
| **Enterococcus faecium** (incl. VRE) | CVK, prolonged antibiotics | Vancomycin resistance |
| **Staphylococcus aureus** (incl. MRSA) | CVK, skin/soft tissue | Methicillin resistance |
| **Klebsiella pneumoniae** | UTI, pneumonia, abdominal | ESBL, KPC |
| **Acinetobacter baumannii** | Ventilator-associated | MDR/XDR |
| **Pseudomonas aeruginosa** | Lungs, CVK, wounds | MDR, biofilm |
| **Enterobacter** spp. | Abdominal, UTI | AmpC inducible |
| **Candida** spp. | CVK, broad antibiotics, steroids | Fluconazole resistance increasing |
| **Coagulase-negative staphylococci** (KNS) | CVK colonization | Methicillin resistance common |

> **GBS-specific data:** In ventilated GBS patients (n=43), bacteremia occurred in 11.6%, candidemia in 4.7%, and line-related infection in 7.4%. Common isolates: *Pseudomonas aeruginosa*, MRSA, *S. pneumoniae*, gram-negative bacilli (Alqahtani et al., *J Int Med Res* 2024).

### Risk Factors for MDR Organisms

- ICU stay >7 days (sharply increased >14 days)
- Prior broad-spectrum antibiotic exposure (especially carbapenems, fluoroquinolones)
- Mechanical ventilation >10 days
- CVC >7 days in situ
- Immunosuppression (corticosteroids, underlying immunodeficiency)
- Prior colonization with MDR organism
- Hospital admission within 90 days

### Mortality Data

| Setting | 30-Day Mortality | Source |
|---------|-----------------|--------|
| ICU-acquired BSI (all) | 25–30% | Buetti et al., ICM 2020. PMID: 32047941 |
| ESKAPE BSI | 27% | Petropoulou et al., 2024 |
| MDR gram-negative BSI | 2× higher than susceptible | Cosgrove, CID 2006. PMID: 16421792 |
| **Inadequate empirical therapy** | **Additional 2–3× mortality risk** | Retamar et al., J Infect 2012 |

## 2. Empirical Antibiotic Selection by Infection Type

*[Level 1 — SSC 2021 guidelines + Strama/SILF]*

**Principle:** Administer empirical antibiotics within 1 hour for septic shock, within 3 hours for sepsis. Always draw 2 sets of blood cultures before antibiotics if this does not delay treatment.

| Suspected Source | First-Line Empirical | Add if High-Risk | Notes |
|-----------------|---------------------|-----------------|-------|
| **VAP** (ventilator-associated pneumonia) | Pip/tazo 4g × 4 or meropenem 1g × 3 | + Vancomycin if MRSA risk | Most common GBS ICU infection (30–78%) |
| **CRBSI** (catheter-related BSI) | Vancomycin + pip/tazo or cefepim | + Echinocandin if candida risk | See section 4 |
| **CAUTI** (catheter-associated UTI) | Cefotaxim 2g × 3 or pip/tazo | Adjust per culture | Remove/replace catheter |
| **Intra-abdominal** | Pip/tazo or meropenem + metronidazol | Consider antifungal | GBS ileus → bacterial translocation risk |
| **Nosocomial sepsis (unknown focus)** | Meropenem 1g × 3 ± aminoglycosid | + Vancomycin + echinocandin | Swedish SILF recommendation |
| **Positive blood culture (organism unknown)** | Vancomycin + meropenem | + Echinocandin if >7d broad AB + CVK | See section 10 |

### Beta-Lactam Infusion Strategy

*[Level 1 — DALI study + SILF 2025 recommendation]*

> **SILF 2025:** ICU patients with sepsis/septic shock should receive beta-lactams via continuous or prolonged infusion (3–4h), NOT standard 30-minute bolus.

**Rationale:** 19.2% of ICU patients fail to achieve target drug levels (50% fT>MIC) with standard bolus dosing. Patients below target are 32% less likely to achieve clinical cure (Roberts et al., *Clin Infect Dis* 2014. PMID: 24429437).

| Drug | Standard Dose | Prolonged Infusion | Continuous |
|------|--------------|-------------------|-----------|
| Pip/tazo | 4g × 4 (30 min bolus) | 4g × 4 (3–4h infusion) | 16g/24h after loading dose |
| Meropenem | 1g × 3 (30 min bolus) | 1g × 3 (3h infusion) | 3–6g/24h after loading dose |
| Cefotaxim | 2g × 3 (bolus) | 2g × 3 (3h infusion) | 6g/24h after loading dose |

## 3. Antibiotic Escalation Algorithm: When Pip/Tazo Fails

*[Level 1 — MERINO trial + IDSA 2024 AMR Guidance]*

### MERINO Trial (Harris et al., JAMA 2018. PMID: 30208454)

RCT, n=378: Pip/tazo was **non-inferior** against meropenem for ESBL-producing *E. coli*/*K. pneumoniae* bacteremia (30-day mortality: pip/tazo 12.3% vs meropenem 3.7%). Study stopped early — **carbapenems are superior for ESBL BSI**.

### Escalation Decision Tree

```
Patient on pip/tazo with clinical deterioration or new positive blood culture
│
├─ Gram-negative organism identified?
│   ├─ YES → ESBL suspected?
│   │   ├─ YES → Switch to MEROPENEM 1g × 3 (prolonged infusion)
│   │   └─ NO → Continue pip/tazo if MIC allows; consider meropenem if AmpC risk
│   └─ Pseudomonas?
│       ├─ YES → Meropenem OR ceftazidim-avibactam + remove CVK
│       └─ NO → Adjust per susceptibility
│
├─ Gram-positive organism identified?
│   ├─ S. aureus → ADD VANCOMYCIN (loading 30 mg/kg, then 15 mg/kg × 3)
│   │              Remove CVK. TEE to exclude endocarditis.
│   │              Duration: minimum 14 days (4–6 weeks if complicated)
│   ├─ KNS → ADD VANCOMYCIN. Consider catheter salvage if uncomplicated.
│   └─ Enterococcus → Vancomycin or ampicillin per susceptibility
│
├─ Yeast/Candida on Gram stain?
│   └─ YES → ECHINOCANDIN immediately + REMOVE CVK
│            (caspofungin 70mg load → 50mg/d, or micafungin 100mg/d)
│
└─ No organism yet / pending?
    └─ Critically ill: MEROPENEM + VANCOMYCIN (± echinocandin)
       Stable: Continue pip/tazo, reassess at 48–72h with culture results
```

### When to Add Vancomycin Empirically (SSC 2021)

- Prior MRSA colonization or infection
- Recent IV antibiotic treatment
- Prolonged ICU stay (>14 days — applies to GBS patients)
- Central venous catheters
- High local MRSA prevalence
- **De-escalate within 48–72h** if cultures negative for MRSA

## 4. CRBSI: Diagnosis, Catheter Removal, and Treatment

*[Level 1 — IDSA 2009 Guidelines, Mermel et al. PMID: 19489710]*

### Diagnosis

| Method | Criteria | Sensitivity | Specificity |
|--------|----------|------------|-------------|
| **Differential time to positivity (DTP)** | CVK culture positive ≥2h before peripheral | ~41% | ~74% |
| **Paired quantitative cultures** | CVK colony count ≥3× peripheral | Higher | Higher |
| **Catheter tip culture (after removal)** | ≥15 CFU (semi-quantitative, Maki roll) | ~85% | ~82% |
| **Clinical suspicion** | Fever, CRP rise, no other focus, CVK in situ | — | — |

> **Important (Mermel 2009):** In immunocompromised patients, a single positive blood culture with skin flora should NOT be dismissed as contamination — may represent true infection.

### Mandatory Catheter Removal

| Organism | Action | Treatment Duration |
|----------|--------|-------------------|
| ***S. aureus*** | **ALWAYS REMOVE** + vancomycin | 14 days minimum; 4–6 weeks if complicated |
| ***Pseudomonas aeruginosa*** | **ALWAYS REMOVE** | 7–14 days |
| ***Candida*** spp. | **ALWAYS REMOVE** + echinocandin | 14 days after first negative culture |
| **Persistent bacteremia >72h** | **ALWAYS REMOVE** regardless of organism | Per organism |
| **Septic shock** | **ALWAYS REMOVE** | Per organism |
| **Tunnel/exit-site infection** | **ALWAYS REMOVE** | Per organism |

### Catheter Salvage May Be Considered

- Organism: KNS or Enterococcus (without complications)
- No sepsis/septic shock
- No tunnel/exit-site infection
- Antibiotic lock therapy possible

### Blood Culture Follow-Up

> **Repeat blood cultures daily until documented clearance** (negative for 48h). Mandatory for *S. aureus* and *Candida*.

### ID Consultation Mandatory

- *S. aureus* or *Candida* bacteremia
- Persistent bacteremia >72h
- Intravascular prosthetic devices
- Metastatic infection (endocarditis, osteomyelitis)

## 5. PCT-Guided Antibiotic Stewardship

### Key Trials

| Trial | N | Key Finding | PMID |
|-------|---|------------|------|
| **PRORATA** (Bouadma et al., Lancet 2010) | 621 | PCT guidance reduced antibiotic days by 23% (10.3 vs 13.3 d), no mortality difference | 20097417 |
| **SAPS** (de Jong et al., Lancet Infect Dis 2016) | 1546 | PCT group: shorter treatment (5 vs 7 d), **lower mortality** (20% vs 25%, p=0.012) | 26947523 |
| **Cochrane meta-analysis** (Schuetz et al., 2023) | >8000 | PCT reduces antibiotic exposure, improves survival | 37540032 |

### PCT Decision Thresholds

| PCT Value | Clinical Action |
|-----------|----------------|
| **≥0.5 ng/mL** | Strong indication for bacterial etiology — start/continue antibiotics |
| **0.25–0.5 ng/mL** | Grey zone — clinical judgment |
| **<0.25 ng/mL** | Low probability of bacterial infection — consider stopping/withholding |
| **Decline ≥80% from peak** | Supports antibiotic discontinuation |
| **<0.5 + ≥80% decline** | SAPS/PRORATA stopping criterion |

### PCT After Corticosteroids

*[Level 2 — multiple studies]*

> **PCT is NOT significantly affected by corticosteroids**, unlike CRP and WBC which are suppressed. This makes PCT the **more reliable infection marker** in patients who have received Solu-Medrol.

- Christ-Crain et al. (*Infection* 2008. PMID: 18330505): CRP suppressed by corticosteroids; PCT specificity preserved
- Raess et al. (*J Clin Pharmacol* 2021. PMID: 34002398): Prednisone did not modify PCT kinetics during treatment

**Clinical implication for post-steroid GBS patients:** CRP may underestimate or show delayed response to bacterial infection. PCT is the preferred marker for initiating, monitoring, and stopping antibiotics.

### PCT in Candidemia vs Bacteremia

| Marker | Bacteremia | Candidemia |
|--------|-----------|------------|
| PCT (median) | **1.73 ng/mL** | **0.29 ng/mL** |
| CRP | Elevated | **Elevated** (cannot differentiate) |

> **Low PCT + rising CRP + risk factors = consider Candida** (Kokkoris et al., 2024)

## 6. Concurrent Bacterial and Fungal Risk

*[Level 2 — IDSA 2016 Candidiasis Guidelines, Pappas et al. PMID: 26679628]*

### When to Add Empirical Antifungal

| Indication | Recommendation | Evidence |
|------------|---------------|----------|
| Fever persisting ≥72–96h on adequate broad-spectrum AB | Add echinocandin | SSC 2021, IDSA 2016 |
| CVK + broad AB >7 days + ICU >10 days | Add echinocandin | IDSA 2016 |
| BDG ≥80 pg/mL + clinical suspicion | Add echinocandin pending cultures | Cochrane (White 2020) |
| Candida colonization ≥2 sites | Calculate Candida Score; treat if ≥3 | Thomas-Rüddel meta-analysis |
| Positive blood culture: yeast on Gram stain | Echinocandin + remove CVK immediately | IDSA 2016 (strong) |

### Candida Score (León et al.)

| Component | Points |
|-----------|--------|
| Total parenteral nutrition | 1 |
| Surgery (current admission) | 1 |
| Multifocal Candida colonization | 1 |
| Severe sepsis | 2 |
| **Score ≥3 → treat empirically** | |

### First-Line Antifungal (Non-Neutropenic ICU)

| Drug | Dosing | Notes |
|------|--------|-------|
| **Caspofungin** | 70mg IV day 1, then 50mg/d | First-line echinocandin |
| **Micafungin** | 100mg IV daily | Alternative echinocandin |
| **Anidulafungin** | 200mg IV day 1, then 100mg/d | Alternative echinocandin |
| Fluconazole | 800mg load, then 400mg/d | Only if NOT critically ill and no prior azole exposure |

### Duration for Candidemia

> Treat for **14 days after first negative blood culture** + resolution of symptoms. Remove CVK as early as possible. (IDSA 2016, strong recommendation)

## 7. Antibiotic Hepatotoxicity and Alternatives

### Piperacillin/Tazobactam Hepatotoxicity

*[Level 3 — retrospective studies + LiverTox database]*

| Parameter | Data |
|-----------|------|
| ALT elevation incidence | 6–15% |
| Bilirubin elevation | 3–5% |
| Injury pattern | Cholestatic or mixed |
| Onset | 1–3 weeks after initiation |
| Mechanism | Immune-mediated (hypersensitivity) |
| Reversibility | Usually self-limited on discontinuation |
| DRESS syndrome risk | >12 reported cases, typically 2–3 weeks |
| Risk factors | Duration ≥7 days (p<0.001), pre-existing liver impairment |

> **Source:** LiverTox NCBI (NBK548825); FDA FAERS analysis, Scientific Reports 2024

### Comparison of Antibiotic Liver Safety

| Antibiotic | Hepatotoxicity Risk | Pattern | Dose Adjustment? | Notes |
|-----------|-------------------|---------|------------------|-------|
| **Pip/tazo** | Moderate (highest among broad-spectrum) | Cholestatic/mixed | No specific, but monitor | Switch if ALT >3× ULN |
| **Meropenem** | Low (Category D) | Mild, transient | No | **Better liver profile than pip/tazo** |
| **Ceftriaxon** | Very low | Rare cholestasis | No | **Safest option for liver** |
| **Cefotaxim** | Very low | Rare | No | Good alternative |
| **Vancomycin** | Minimal hepatic | Rare | Renal monitoring needed | Safe for liver |
| **Aminoglycosides** | Not hepatically metabolized | None | Renal monitoring | Safe for liver, nephrotoxic |
| **Ciprofloxacin** | Low | Minimal | No | |
| **Metronidazol** | Moderate in high dose | Dose-dependent | Yes in severe impairment | Avoid prolonged courses |

### Practical Recommendation: Liver Impairment on Pip/Tazo

```
Liver values rising on pip/tazo
│
├─ ALT <3× ULN → Monitor LFTs 2–3×/week, continue pip/tazo
├─ ALT 3–5× ULN → Consider switching to MEROPENEM
│                  (better liver safety + broader coverage)
├─ ALT >5× ULN or bilirubin rising → SWITCH immediately
│   ├─ First choice: Meropenem 1g × 3 (prolonged infusion)
│   ├─ Alternative: Ceftriaxon + metronidazol (narrower but liver-safe)
│   └─ Add vancomycin if MRSA risk (liver-safe, renal monitoring)
│
└─ Watch for DRESS syndrome: rash + fever + eosinophilia + liver dysfunction
   → Stop pip/tazo immediately, consider corticosteroid treatment
```

## 8. IgA Deficiency: Heightened Surveillance Protocol

*[Level 3 — cohort data + pathophysiology]*

### Why IgA-Deficient ICU Patients Are at Higher Risk

| Factor | Impact | Source |
|--------|--------|--------|
| Absent secretory IgA at mucosal surfaces | Impaired barrier against respiratory, GI, urogenital pathogens | Vosughimotlagh 2023 |
| 18.5% fungal infections in IgA-deficient patients | Baseline candida risk elevated | Vosughimotlagh 2023 |
| Reduced bronchial IgA predicts nosocomial pneumonia | VAP risk increased | Annane 1996 |
| Broad-spectrum antibiotics suppress residual mucosal IgA production | "Double IgA deficiency" — congenital + antibiotic-induced | Robak et al., Nat Med 2018. PMID: 29771684 |
| Steroids + IgA-brist + broad AB | Synergistic mucosal defense gap | Clinical reasoning |

### Enhanced Surveillance Protocol (IgA-Deficient ICU)

| Test | Frequency | Threshold | Notes |
|------|-----------|-----------|-------|
| **Blood cultures** (CVK + peripheral) | Every fever ≥38.0°C | Lower threshold than standard (38.5°C) | Single positive should NOT be dismissed |
| **PCT** | Daily during active infection; 2–3×/week otherwise | More reliable than CRP post-steroids | |
| **CRP** | Daily | Trend more important than single value | May be suppressed by steroids |
| **BDG (beta-D-glucan)** | 1–2×/week when on broad AB + CVK | ≥80 pg/mL suspicious; ≥112 pg/mL optimized ICU cutoff | Screen for invasive Candida |
| **Surveillance cultures** (tracheal aspirate, urine, rectal swab) | 2×/week during high-risk periods | Colonization index >0.5 predicts invasion | |
| **Liver function** (ASAT, ALAT, ALP, bilirubin, GT) | 2–3×/week on hepatotoxic antibiotics | See section 7 | |
| **Fungal cultures** (blood, tracheal) | With every new fever on broad AB | Especially after >7 days broad AB | |

### Lower Thresholds for Empirical Treatment

- Start empirical antibiotics at **any hemodynamic instability + fever**, not just septic shock
- Broaden empirically at **new fever during existing antibiotic therapy** (do not wait 72h)
- Add antifungal coverage at **lower threshold** than standard patients:
  - Fever ≥48h (not 72–96h) on adequate broad-spectrum AB
  - BDG borderline (60–80 pg/mL) in context of risk factors
  - Single site Candida colonization + clinical deterioration (rather than requiring ≥2 sites)

## 9. Swedish Guidelines: Empirical Regimens (Strama/SILF)

### Nosocomial Sepsis (>48h In-Hospital, Unknown Focus)

*Source: SILF Sepsis Vårdprogram 2022/2023, Narkosguiden*

| Severity | Regimen | Notes |
|----------|---------|-------|
| Sepsis | Pip/tazo 4g × 4 (prolonged infusion) | Or meropenem 1g × 3 |
| Septic shock | Meropenem 1g × 3 + aminoglykosid (tobramycin 7 mg/kg × 1) | Extra dose at half interval between dose 1 and 2 |
| + MRSA risk | Add vancomycin (load 30 mg/kg max 2g, then 15 mg/kg × 3) | Check trough before 4th dose |
| + Candida risk | Add echinocandin (micafungin 100mg/d) or fluconazole (load 800mg, then 400mg) | Echinocandin if sepsis/critically ill |

### Catheter-Related Suspected Infection

| Component | Regimen |
|-----------|---------|
| Empirical | Vancomycin + gram-negative coverage (pip/tazo or cefepim or meropenem) |
| Candida risk | Add echinocandin |

### De-Escalation (SILF/SSC 2021)

- Reassess at **48–72 hours** based on culture + susceptibility results
- De-escalate to narrowest effective spectrum
- **ID consultation within 24 hours** for complex ICU infections (recommended)
- **Infektionsjour finns även på helg** — ska kontaktas vid positiv blododling

### Prolonged Beta-Lactam Infusion (SILF 2025)

> **New recommendation:** All ICU sepsis patients should receive beta-lactams via continuous or prolonged infusion. Evidence: improved target attainment, trend toward lower mortality.

## 10. Decision Algorithm: Positive Blood Culture in GBS ICU

```
POSITIVE BLOOD CULTURE — organism pending
│
├─ 1. DRAW REPEAT CULTURES (2 sets: CVK + peripheral) — STAT
│
├─ 2. GRAM STAIN AVAILABLE?
│   ├─ Gram-positive cocci → ADD VANCOMYCIN (load 30 mg/kg)
│   │   ├─ Clusters (staph) → Assess CVK as source, plan removal
│   │   └─ Chains (strep/enterococcus) → Continue vancomycin
│   │
│   ├─ Gram-negative rods → Assess current coverage
│   │   ├─ On pip/tazo → Consider escalation to MEROPENEM
│   │   │   (especially if ESBL risk or clinical deterioration)
│   │   └─ Add aminoglycoside if septic shock
│   │
│   ├─ Yeast → ECHINOCANDIN immediately + REMOVE CVK
│   │
│   └─ Not yet available → Empirical: MEROPENEM + VANCOMYCIN
│       (+ echinocandin if >7d broad AB + CVK + steroid history)
│
├─ 3. ASSESS CATHETER
│   ├─ CVK in situ >7 days? → Low threshold for removal
│   ├─ Tunnel/exit-site infection? → Remove immediately
│   ├─ No other identified source? → CVK is likely source
│   └─ DTP: CVK culture positive ≥2h before peripheral → CRBSI likely
│
├─ 4. ADDITIONAL DIAGNOSTICS — STAT
│   ├─ PCT (fresh, not >24h old)
│   ├─ BDG (beta-D-glucan) if not done
│   ├─ CRP
│   ├─ LFTs (if on hepatotoxic antibiotics)
│   └─ Lactate (if hemodynamically unstable)
│
├─ 5. MONITOR
│   ├─ Daily blood cultures until clearance (48h negative)
│   ├─ PCT trend (>80% decline from peak → supports stopping)
│   ├─ Clinical response at 48–72h
│   └─ Culture + susceptibility → de-escalate when available
│
└─ 6. CONSULT
    ├─ Infektionsjour (available weekends/holidays)
    ├─ ID consultation within 24h for any ICU bacteremia
    └─ MANDATORY for S. aureus, Candida, persistent bacteremia >72h
```

### Madeleines Specific Risk Matrix

| Risk Factor | Present | Clinical Implication |
|------------|---------|---------------------|
| ICU >14 days | ✓ | ESKAPE pathogen risk, MDR screening |
| Mechanical ventilation >10 days | ✓ | VAP risk, surveillance cultures |
| CVK in situ | ✓ | CRBSI risk, low removal threshold |
| Broad-spectrum AB >7 days | ✓ | Candida risk, resistance selection |
| Corticosteroids (recent) | ✓ Solu-Medrol ended 2/4 | Immunosuppression ~2 weeks |
| IgA deficiency (congenital) | ✓ | Mucosal barrier compromise |
| Previous Candida infection | ✓ | Heightened fungal vigilance |
| Dysautonomia | ✓ | Gut dysmotility → translocation risk |
| Liver impairment | ✓ | Limits antibiotic choices |

**Risk stratification: VERY HIGH** — essentially all major risk factors present. Warrants aggressive empirical coverage and enhanced surveillance.

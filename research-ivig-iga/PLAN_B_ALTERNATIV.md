# Behandlingsalternativ efter PE5 — Svår recidiverande GBS med IgA-brist

**Patient:** Madeleine, 52 år. Selektiv IgA-brist. Recidiverande GBS (1:a episod vid 16 års ålder).
**Datum:** 2026-03-26
**Status:** PE4 genomförd. PE5 planerad 2026-03-27. Nära total förlamning. Respiratorberoende. Trakeostomi dag 1.

---

## Fråga: Vad finns om PE5 inte ger tillräcklig effekt?

Nedan sammanfattas publicerade behandlingsalternativ vid PE-refraktär GBS, anpassade för patient med **selektiv IgA-brist**. Alla alternativ utom IVIg saknar IgA-relaterad anafylaxirisk.

---

## Alternativ 1: Efgartigimod (Vyvgart) — off-label

| | |
|---|---|
| **Mekanism** | FcRn-hämmare — accelererar nedbrytning av patogena IgG-antikroppar |
| **IgA-säkert** | Ja — innehåller ingen immunoglobulin |
| **Evidens vid GBS** | 6 publicerade fallrapporter (2024-2026) vid IVIg/PE-refraktär GBS, inklusive ventilatorsberoende patienter. Retrospektiv analys n=17: 1-poängs GBS-DS-förbättring inom 4 dagar (Cheng et al., Sci Rep 2026). |
| **Dosering** | 10 mg/kg IV, 1x/vecka i 4 veckor |
| **Tillgänglighet** | EMA-godkänt i Sverige för MG (2022) och CIDP (2024). Off-label vid GBS möjligt via sjukhusapotek. |
| **Timing efter PE** | 24-48 timmar efter sista PE. Ingen farmakologisk konflikt. |
| **Kontakt** | argenx: medinfo@argenx.com |

> Hu BQ et al. Efgartigimod for treating GBS with poor response to IVIg. *BMC Neurol* 2025. PMID: 41029230
> Ripellino P et al. Efgartigimod as add-on in refractory GBS. *Eur J Neurol* 2025. PMID: 40799081
> Cheng Y et al. Rapid neurological recovery in GBS treated with efgartigimod. *Sci Rep* 2026. PMID: 41851318

## Alternativ 2: IVIg med lågt IgA-innehåll (Privigen)

| | |
|---|---|
| **Mekanism** | Poolat humant IgG — immunmodulerande |
| **IgA-risk** | Privigen: IgA ≤25 µg/mL. Patienten har tidigare tolererat Gamanorm SCIG (IgA ≤82,5 µg/mL) i ca 2-3 år utan reaktion. Privigen har *lägre* IgA. |
| **Evidens vid GBS** | Level 1 — Cochrane systematic review. Ekvivalent med PE. |
| **Dosering** | 0,4 g/kg/dag i 5 dagar (totalt 2 g/kg) |
| **Förutsättningar** | Anti-IgA-antikroppar (IgE + IgG) bör testas först. Premedicinering: paracetamol + antihistamin + hydrokortison. Långsam infusionsstart (0,5 mL/kg/h). Adrenalin i beredskap. IVA-miljö optimal. |
| **OBS** | Inte en *andra* IVIg-kur (SID-GBS-studien avråder). Detta är en *första* IVIg-kur efter PE — annan klinisk situation. |
| **Timing efter PE** | ≥48 timmar efter sista PE |

> Rachid R, Bonilla FA. Anti-IgA antibodies review. *JACI* 2012. PMID: 21835445
> Martinez C et al. IVIG anaphylaxis declining. *Clin Exp Immunol* 2021. PMID: 34562316

## Alternativ 3: Imlifidase (Idefirix) — compassionate use

| | |
|---|---|
| **Mekanism** | Enzym som klyver alla IgG-subklasser inom timmar. Selektivt — påverkar INTE IgA, IgM eller koagulationsfaktorer. |
| **IgA-säkert** | Ja — interagerar inte med IgA |
| **Evidens vid GBS** | Fas 2 (n=30): median 6 dagar till 1-grads förbättring. 67% gick självständigt vid 8 veckor. 6 veckor snabbare återhämtning jämfört med kontrollkohort (IGOS, n=754). |
| **Dosering** | 0,25 mg/kg IV engångsdos |
| **Tillgänglighet** | Compassionate use via Hansa Biopharma, Lund |
| **Kontakt** | **Hansa Biopharma AB, Lund.** Tel: +46 46 16 56 70. E-post: medinfo@hansabiopharma.com. Hemsida: hansabiopharma.com |
| **Fördel** | Företaget ligger i Lund — geografisk närhet underlättar snabb leverans. |

> Hansa Biopharma Phase 2 full results, December 2024. hansabiopharma.com

## Alternativ 4: Rituximab

| | |
|---|---|
| **Mekanism** | Anti-CD20 monoklonal antikropp — depleterar B-celler |
| **IgA-säkert** | Ja — monoklonal antikropp |
| **Evidens vid GBS** | Fallrapporter vid refraktär GBS (PMID: 38549594). Särskilt indicerat om paranodala antikroppar (anti-NF155/CNTN1) påvisas. |
| **Dosering** | 375 mg/m² IV veckovis x 4, eller 1 g IV dag 1 + dag 15 |
| **Tillgänglighet** | Rutinpreparat på svenska sjukhus (används vid RA, lymfom, MS m.fl.) |
| **OBS** | Starkast indicerat om paranodal antikroppstestning visar positivt resultat |

## Alternativ 5: Tanruprubart (ANX005) — compassionate use

| | |
|---|---|
| **Mekanism** | Anti-C1q monoklonal antikropp — hämmar klassiska komplementkaskaden |
| **IgA-säkert** | Ja — monoklonal antikropp |
| **Evidens** | Fas 3 RCT positiv (n=242): OR 2.4 (p=0,006) för förbättring vid vecka 8. Patienter gick 31 dagar tidigare. 28 färre respiratordagar. **Starkast evidens av alla nya terapier.** |
| **Dosering** | 30 mg/kg IV engångsdos |
| **Tillgänglighet** | EMA MAA under granskning (insänd jan 2026). Ej kommersiellt tillgängligt ännu. Compassionate use kan behöva förhandlas. |
| **Kontakt** | Annexon Biosciences: medicalinfo@annexonbio.com |

> Wiegers EJA, Jacobs BC. New insights in GBS immune treatment. *Curr Opin Neurol* 2025. PMID: 40748027

## Vad man INTE bör göra

| Undvik | Anledning | Evidens |
|--------|-----------|---------|
| Upprepad IVIg-kur (om IVIg redan givits) | Ingen nytta, ökade allvarliga biverkningar (35% vs 16%) | SID-GBS RCT (PMID: 33743237) |
| Kortikosteroider ensamt | Ingen effekt vid GBS, kan fördröja återhämtning | Cochrane systematic review |
| Avvakta utan plan | Tidig insats ger bättre resultat | Konsensus |
